# 📊 Test Report Summarizer

**Test Report Summarizer** is a Java-based desktop application that allows users to load and parse XML test reports and generate structured Excel summaries. Designed with a user-friendly Swing interface, it streamlines the process of interpreting automated test results from complex test suites.

# ✨ Features

- 🧾 Load and parse XML-based test reports
- 📊 Generate summarized Excel reports automatically with statistics and charts
- 🔄 Can load and parse multiple reports in one go
- 🖥️ Intuitive Swing GUI
- 📦 Built using Maven for easy dependency management


# 🛠️ Prerequisites

- Java 8 or later
- Maven 3.x
- Eclipse or any Java IDE (optional)
